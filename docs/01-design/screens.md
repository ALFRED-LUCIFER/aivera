# Screen map

Every screen is an artboard in the claude.ai Design canvas "Credalent — Evidence Intelligence", copied verbatim into [`artboards/`](artboards/) (with `canvas.json`, the canvas layout) so every agent, reviewer and Copilot can read it. Open the file before building or reviewing its screen (AGENTS.md section 4); deviations are listed in the component and the PR. The artboard is the spec for layout and copy; [DESIGN.md](../../DESIGN.md) is the spec for tokens and components. Interactive states named in the artboard (preview, sent, done…) are the states the screen must implement.

**The job has seven stages** in the canvas: Job and rubric, Bring in candidates, Evidence, Ranking, Calibrate, Interviews, Decision (`Rubric`, `Import`, `Evidence`, `Candidates`, `Calibrate`, `Interviews`, `Pack`). The code has six (`jobHeader.stages` in `packages/i18n`): Bring in candidates shipped with its page (AIV-P1-101); the ticket that adds the rest (AIV-P1-100) updates the header, routes and this table. Emails sent from a workspace carry its logo, accent colour and name with "Powered by Credalent" (`ELayout.dc.html`).

Routes are planned; the ticket that builds a screen confirms its route and updates this table.
